## 产物与安装

- 项目根目录的 `搞整理.app` 是最新版程序；`Sources/`、`Resources/`、`Assets/`、`Tests/`、`Scripts/` 为全部源码与构建资源。

- 独立仓库：[UCASerYff/GaoZhengLi](https://github.com/UCASerYff/GaoZhengLi)，当前发行 [v1.00](https://github.com/UCASerYff/GaoZhengLi/releases/tag/v1.00)。发布内容只含程序、源码、图标、说明、许可和摘要。

## 实际命令与结果

```sh
Scripts/test.sh
GAOZHENGLI_SIGN_IDENTITY=<已核实证书 SHA-1> Scripts/build.sh
python3 Scripts/install.py <本项目>/搞整理.app
codesign --verify --deep --strict /Applications/搞整理.app
hdiutil verify dist/GaoZhengLi-1.00.dmg
gh release download v1.00 --repo UCASerYff/GaoZhengLi --dir <隔离临时目录>
shasum -a 256 -c SHA256SUMS
```

最后源变更只影响备份模块，已单独执行并通过 4 项备份回归；最后索引变更后重跑 IndexTests；配置/标记变更后重跑 23 项关联/配置测试。Move/Exchange 源码冻结后未变。编译为 `-target arm64-apple-macos14.0`，本机 macOS 27.0.1 / Xcode 27.0 / Swift 6.4（Swift 5 语言模式）。不把在本机编译当作 macOS 14 真机兼容性验收。

最新索引样本：2000 原创小文件、本机临时 APFS 存储，首扫 0.250s、复扫 0.689s、查询 11 项约 0.004662s。完整测试进程 CPU 1.106s、peakRSS 27.92MiB（包含造数据和所有断言，不是独立首扫资源）。不能据此声称所有场景即时。
